GradCafe Application Analysis

Live analysis from the PostgreSQL applicants table using SQLAlchemy.

Pull Data reuses the Module 2 scraper to check GradCafe for newly submitted application results and add new usable records to PostgreSQL. Because GradCafe may require browser verification, keep one verified /survey tab open in the debug-Chrome session before starting a pull.

Update Analysis only re-queries PostgreSQL. It never starts or interrupts a scrape, so it is safe to use while Pull Data is running.
